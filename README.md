A Python program — standard library only, no network — that writes exactly one word to /output/entry.txt: "Loveyou", the classic grandma sign-off sent as the entire message, the word a grandma would text about AI. The word is 7 characters, inside the competition's gate of exactly one word of 1 to 30 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
